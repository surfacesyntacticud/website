[Rhapsodie](https://rhapsodie.modyco.fr/) is a rich treebank of French spoken data.
It is available in several different formats that are listed below.

See also [SUD_French-Rhapsodie's README](https://github.com/surfacesyntacticud/SUD_French-Rhapsodie/blob/master/README.md#development) for more details on the way formats are maintained.

## Regular token-based syntax

| Format |  ![Surface Syntactic Universal Dependencies (SUD)](/images/sud.svg)  |   ![Universal Dependencies (UD)](/images/ud.svg)   |
|-----|-----|------|
| Regular | [SUD_French-Rhapsodie@latest](https://universal.grew.fr/?corpus=SUD_French-Rhapsodie@latest) | [UD_French-Rhapsodie@conv](https://universal.grew.fr/?corpus=UD_French-Rhapsodie@conv) |
| p_words (without mutli-word tokens) | [SUD_French-Rhapsodie@p_words](https://universal.grew.fr/?corpus=SUD_French-Rhapsodie@p_words) |  |
| Dependency-based (see [draft](https://docs.google.com/document/d/1EwAirGG7U3riZPsT04TzIOoQJ60atj3mUi-TnEKL0oE)) | [SUD_French-Rhapsodie@db](https://universal.grew.fr/?corpus=SUD_French-Rhapsodie@db) | [UD_French-Rhapsodie@db](https://universal.grew.fr/?corpus=UD_French-Rhapsodie@db) |

## With prosodic annotation layer


| Format |  ![Surface Syntactic Universal Dependencies (SUD)](/images/sud.svg)  |
|-----|-----|
| With syllables as tokens | [pSUD_French-Rhapsodie@latest](https://universal.grew.fr/?corpus=pSUD_French-Rhapsodie@latest) |
